# Hosting and custom subdomain

Requested hostname: axl.sssom.com. The parent sssom.com resolves to Cloudflare nameservers laura.ns.cloudflare.com and ryan.ns.cloudflare.com. Only the axl host belongs to this task; parent records, www, MX, TXT and other applications must remain unchanged.

## Public preview first
The currently supported deployment is a public GitHub Pages project preview at https://contato675.github.io/axl-portfolio/. Source lives on feat/axl-portfolio and generated output on pages-preview. No source-branch merge is required. This prevents an unconfigured custom domain from making the only preview inaccessible.

## Prepared custom-domain output
`npm run build:domain` emits dist-domain with CNAME= axl.sssom.com, origin https://axl.sssom.com and basePath /. Both languages, release pages, assets, canonical/hreflang, Markdown and discovery files use that root. This is a tested local build, not proof that the hostname is online.

## Required Cloudflare record
| Type | Name | Target | Proxy |
|---|---|---|---|
| CNAME | axl | contato675.github.io | DNS only during GitHub verification/certificate provisioning |

Before creating the DNS record, associate axl.sssom.com with this GitHub Pages repository and publish the root build. Verify there is no existing axl record or application before changing it. Account-level TXT verification is recommended and uses the exact challenge generated by GitHub, never an invented value. No wildcard or changes to sssom.com itself.
Once Cloudflare resolves the CNAME, wait for GitHub to issue its TLS certificate and enable/verify HTTPS enforcement. Check the live hostname, /pt-br/, all release links, CNAME, images, robots and the output manifest. Never disable TLS verification to call the host ready.

## Current integration boundary
A plugin-directory search for Cloudflare returned no available management integration. No wrangler CLI was present in the checked location, and no Cloudflare token was read. axl.sssom.com returned NXDOMAIN during the preflight. No DNS change has been attempted through another account or an unrelated tool.

## Discovery
The preview keeps meta noindex and an empty sitemap. llms.txt and Markdown are available as reading aids, not guarantees of ranking, acceptance or training protection. On a custom host robots.txt is at the correct origin root; publish its final policy and indexation only after editorial approval. At the github.io project subpath its robots copy does not control the entire origin.
