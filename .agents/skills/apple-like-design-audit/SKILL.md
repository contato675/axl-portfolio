# A.X.L. design audit
Read AGENTS.md and docs/design.md. This is an original project contract, not an Apple certification or a redistributed SSSOM third-party skill.
Use black neutral surfaces, Inter body and Archivo display with expanded width. Music and genuine imagery supply the personality. Keep 12/8/4 columns, 8px rhythm, coherent alignment and uncropped covers.
Check every layout at 320,390,480,768,1024,1440,1920 in EN and PT-BR. Evaluate overflow, real grid placement, minimum 44px controls, usable names/focus, image decode, actual fonts and hidden disclosure states.
Test all real release dialogs, keyboard, Escape, browser history, focus restoration, mobile menu including languages, reduced motion, no-JavaScript routes and custom-root paths. YouTube frames must not exist before consent. Do not autoplay or download audio.
Run npm run verify and npm run design:apple. Inspect small viewport screenshots from artifacts/apple-like and version the measured JSON result. Missing media, unavailable domains and failed tests cannot be reported as done.
Retain noindex until final editorial approval. Physical-device gestures, assistive technology, optical/colour approval and field performance are not implied by passing automated checks. Never weaken browser policies or ship debug grids to visitors.
